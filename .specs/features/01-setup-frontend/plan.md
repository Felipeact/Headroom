# 01 - Frontend scaffold

## Problem

The repository has no web app. Every frontend spec after this one (06 design system, 07 app shell,
09 typed client, 10 login, and every screen) needs a Next.js project with Tailwind and shadcn/ui
to build on, and none can start until one exists. Starter code written from memory is the failure
the roadmap's set-up decision exists to avoid ("Generated code is accurate; boilerplate written from
memory often isn't"), so the scaffold has to come from the official generators, unedited.

When this ships, `frontend/` runs locally, builds, and accepts `npx shadcn@latest add` for spec 06.
The source gives no evidence beyond the roadmap's build order.

## Flow

Reuses the official generators end to end; the only hand-written change is one line in the
generated `frontend/AGENTS.md`.

0. hand edit - root `.gitignore` excluding `.env*` except `.env.example`, the missing "Before spec 01" prerequisite (user: "generate all files necessary")
1. `npx create-next-app@16.3.8 frontend --yes --tailwind --eslint --app --no-src-dir --use-npm` (door 1) - creates `frontend/` with `app/`, `package.json`, `package-lock.json`, `.gitignore`, `AGENTS.md`, `CLAUDE.md`; skips `git init` because the root is already a repository
2. `npx shadcn@4.21.1 init` in `frontend/` (door 2) - writes `components.json`, `lib/utils.ts`, `components/ui/button.tsx`, the theme variables in `app/globals.css`, the preset font in `app/layout.tsx`, and its dependencies
3. hand edit - prepend one line to `frontend/AGENTS.md` (created by door 1)
4. out: `npm run dev` serves the starter page on `http://localhost:3000`; `npm run build` produces `.next/`

## Criteria

### S1: The app runs and builds (P1)

A developer can start and build the generated app with no hand-written code.

**Acceptance Criteria**

1. WHEN `npm run build` runs in `frontend/` after both generators THEN it SHALL exit 0
2. WHILE `npm run dev` runs in `frontend/`, WHEN `GET http://localhost:3000/` is requested THEN the system SHALL respond `200` with the create-next-app starter page
3. WHEN `npm run lint` runs in `frontend/` THEN it SHALL exit 0
4. The frontend SHALL have `frontend/app/layout.tsx`, `frontend/package-lock.json`, `frontend/tsconfig.json` with `"strict": true`, and no `frontend/src/` directory
5. The frontend `package.json` SHALL depend on `next` `16.3.8`

### S2: shadcn/ui is initialized (P1)

Spec 06 can run `npx shadcn@latest add` without re-initializing.

**Acceptance Criteria**

6. The system SHALL have `frontend/components.json` produced by `shadcn init`, with `"rsc": true`, `"tsx": true`, and `tailwind.cssVariables` `true`
7. The system SHALL have `frontend/lib/utils.ts` exporting `cn`, as generated by `shadcn init`

### S3: Generated output stays unedited (P1)

The only hand-written change is the agent-guidance line.

**Acceptance Criteria**

8. The first line of `frontend/AGENTS.md` SHALL be exactly: Also follow the root `AGENTS.md` and `context/DESIGN.md`.
9. The `<!-- BEGIN:nextjs-agent-rules -->` ... `<!-- END:nextjs-agent-rules -->` block of `frontend/AGENTS.md` SHALL be byte-identical to the generator output
10. WHEN the generator output is committed THEN the next commit touching `frontend/` SHALL change only `frontend/AGENTS.md`
11. IF any file matching `frontend/.env*` exists THEN `git ls-files frontend` SHALL list none of them
12. The root `.gitignore` SHALL make `git check-ignore` ignore `services/core/.env.local` and not ignore `services/core/.env.example`

**Independent test:** clone at `HEAD`, `cd frontend && npm ci && npm run lint && npm run build`, then `git diff --stat <generator commit>..HEAD -- frontend` shows one file.

## Assumptions

| Assumption | Chosen default | Rationale | Confirmed? |
| --- | --- | --- | --- |
| shadcn component base library | `radix` | user answered "tailwind css", which every base uses; recommended default applied - broadest documentation for the components spec 06 adds. Re-initialising before spec 06 is cheap | n |
| shadcn preset, RTL, monorepo prompts | shadcn's default preset for the base, `--no-rtl`, `--no-monorepo`, `--css-variables` | v1 is English only, single app; `DESIGN.md` requires CSS variables; spec 06 replaces the colours anyway | n |
| Generator versions | pin `create-next-app@16.3.8` and `shadcn@4.21.1`, the `@latest` of 2026-10-01 | the spec's `@latest` resolves to these today; pinning keeps the build reproducible | n |
| Commit split | commit 1: raw generator output; commit 2: `frontend/AGENTS.md` line and spec status | makes AC 10 provable with `git diff` | n |

**Open questions:** none - all resolved or logged above. The missing root `.gitignore` is now AC 12.
